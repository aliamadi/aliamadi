# Alireza Ahmadi

**Senior Front-End Engineer** · Front-End Tech Lead at [Ghasedak24](https://ghasedak24.com/)

Senior Front-End Engineer with nearly 8 years building web products, now focused on TypeScript, React, Next.js and Vue 3. I specialize in front-end architecture and legacy modernization, turning complex codebases into fast, maintainable platforms without slowing delivery.

As Front-End Tech Lead at Ghasedak24, a travel booking platform with up to 660K monthly organic search clicks, I lead the move from a legacy Vue 2 and jQuery front end to Next.js and Feature-Sliced Design: the customer panel is live, and the hotel and insurance sections are in final review. I built the design system and release pipeline, and mentor the team.

## What I work on

- **Modernizing legacy front ends.** Led our migration to Next.js on Feature-Sliced Design, running the old and new systems side by side. An architecture-check script runs on every push and fails when FSD rules are broken.
- **Performance, measured.** The August 2025 public-page cutover removed about 330 kB of legacy JavaScript from every public page; that month mobile INP p75 fell from 200–225 ms to 150–175 ms and CLS moved into "good" (Chrome UX Report). Per-product entry points cut the booking search box's initial bundle by 75–80%. Ongoing work with the team has brought mobile INP to 127 ms and LCP to 1.69 s.
- **The platform a team ships on.** A Tailwind CSS and Flowbite React design system with 42 components in a Turborepo monorepo, and blue/green releases on GitLab CI/CD with Docker and Nginx, a staging gate and one-step rollback.
